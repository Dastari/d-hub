Delete works reliably and previews are tighter.

- Delete no longer stops working after you type and erase a reply. It releases an empty draft, then dismisses and marks read. While browsing it always dismisses, except for a message whose reply has text.
- The composer says "LOCKED · empty, Del releases" when a locked reply has no text. Switching messages drops an empty draft instead of saving it.
- HTML mail no longer draws table borders, and table rules are skipped in previews.
- The preview drops blank lines; the full reader (`o`) keeps single paragraph breaks.
- Account names that only repeat the provider ("iCloud · iCloud") are shown once.

Real-account acceptance for Teams, Office 365 and iCloud is still pending the owner's sign-in. Still unknown: whether iCloud saves a Sent copy of replies. No license has been selected.
