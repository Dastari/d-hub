Replies wrap, help fits a narrow drawer, and email previews drop stray CSS.

- **Wrapping replies.** Typing in the reply box wraps at words instead of running off the edge. The box grows with the wrapped lines up to six, and Alt+Up/Down move between them.
- **Help for a narrow drawer.** `?` shows keys beside their descriptions when there's room and stacks them when the drawer is narrow. Demo-only controls are hidden when you're connected to real accounts.
- **Reply follows what's shown.** After changing focus or source, dismissing, or showing dismissed items, an empty reply goes to the highlighted message, or to nobody when nothing is showing. It never stays on a message you can't see. A draft with text is never moved.
- **Cleaner email previews.** iCloud mail now shows the HTML version, as mail apps do, so CSS from senders like ClearScore no longer appears. Mail without HTML falls back to plain text. Messages already fetched keep their old preview.

Wrapping hasn't been checked in Ghostty or Windows Terminal. Opening links from the keyboard isn't supported yet. Decision quality on real mail is untested. Real-account acceptance for Teams, Office 365 and iCloud is still pending the owner's sign-in. No license has been selected.
