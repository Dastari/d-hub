Settings are edited where they are shown.

- Choosing a value on the settings page turns that row into an input; the rest of the page stays visible. Enter saves, Esc cancels, and a rejected value keeps the row open with the reason.
- Prompts, term lists and Teams chat IDs wrap inside the row. Enter adds a line and Ctrl+S saves.
- Passwords and API keys entered from an account's **Sign in** row or **Store API key** are typed into that row and shown as dots.
- `:spam prompt` and `:profile prompt NAME` open the settings row for that field, already editing.

Real-account acceptance for Teams, Office 365 and iCloud is still pending the owner's sign-in. Known gaps: iCloud reconnects on every poll; reactions or edits can resurface old Teams messages; quoted Teams replies show a false files marker; Office 365 replies may omit the quoted original.
